AIRSHOW BEFORE / AFTER — SHAREABLE STATIC WEBPAGE

OPEN LOCALLY
1. Keep index.html and the assets folder together.
2. Double-click index.html.

SHARE ONLINE
Upload the entire unzipped folder to any static web host (GitHub Pages,
Netlify, Cloudflare Pages, or similar). No server code or database is needed.

INTERACTION
- Drag left/right across a photo for the before/after slider.
- Use Toggle view to jump between the original and edit.
- Global buttons switch every card at once.
- Category buttons filter the gallery.
- Keyboard: Left/Right adjusts the slider, Home/End jumps to either side.

The page has no external dependencies, analytics, or third-party scripts.
